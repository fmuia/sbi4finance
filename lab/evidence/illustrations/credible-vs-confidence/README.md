# Credible versus confidence intervals (toy model)

`l10-credible-vs-confidence.png` compares the coverage of posterior and Gauss–Newton 90%
intervals in a two-parameter toy model: for a truth near the prior bound, a truth inside
the box, and truths drawn from the prior (right panel: by the true rho).

It was drawn by `course/scripts/lecture10.py` for Lecture 8 of the background course. The
course was removed from the repository on 17 November 2026; the script and lecture are at
commit [`9e175a6`](https://github.com/fmuia/sbi4finance/tree/9e175a683a3a0d72185493e31fb8244a76e14d0f/course).
