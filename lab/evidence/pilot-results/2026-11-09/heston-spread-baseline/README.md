## What changed

The new `HestonSpreadPilot` uses one independent Gaussian price SD `c * half_spread`. The initial target fixes c=1 and infers five physical parameters. A separate target appends c with the declared illustration prior Uniform(.5,2); c is not a conditioning feature for that target. The implementation includes likelihoods, deterministic seeded simulation, immutable task validation, a normalized one-dimensional conditional-c oracle, bounded native PyMC references, fixed-layout neural trainers, exact first-failure capture and matched development evaluations. The inferred-c network and its distinct limitations are recorded in the subsequent noise-scale study.

Checked Fourier pricing is reused from the earlier `HestonPilot`, ported unchanged from historical study commit `78cf9de`. The executing financial model remains in the participant runtime. The new spread-only initializer needs no observed IV or vega and accepts arbitrary finite Gaussian observations, including negative values. Numerical precision remains gated against `.5 * half_spread`, independently of inferred c.
