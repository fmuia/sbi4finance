Same observations, separate truth and inference

Yᵢ=Pᵢ(φ)+c hᵢ Zᵢ,   Zᵢ∼N(0,1)

The known half-spreads hᵢ set quote-specific scales; c is one unknown multiplier shared by the quotes in a dataset. The sampler receives the 54 noisy option quotes and infers all five physical Heston parameters and c jointly. Generating parameters, clean prices and noise realizations are not available to it. This is not a fixed-physical oracle. The two networks use their saved 500-pass posterior quantiles for exactly the same existing validation rows; no network is queried again.

Cases were fixed before sampling by stable-sorting the 512 generating c values and choosing one midpoint rank in each of eight equal rank strata. Selection uses no neural error or MCMC result, and failed cases are not replaced. This selected panel is not a new SBC or population coverage study.

Every vertical bar is a central 90% posterior credible interval, not a Monte Carlo standard-error bar. Finite quote noise and the prior permit uncertainty and shrinkage: even correct posterior medians need not lie exactly on the unit line for every dataset.
