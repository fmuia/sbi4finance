Heston learned summaries: complete fixed-grid comparisons

Development evidence only. Final epoch 300 is primary. The minimum native validation-loss checkpoint is secondary and is shown separately; it was not selected by posterior diagnostics. These results reuse historical development cases, retain every raw draw and do not establish fresh acceptance or a sufficient statistic.

All fits use 300,000 stored noisy data sets, 63 actual contracts, the same frozen ZCA transform, broad physical priors and inferred Gaussian noise multiplier c. A learned MLP summary layer is added before the same FlowMatching posterior head. The MLP fits use the same declared seed; changing the architecture changes weight shapes and random-number use, so a one-seed screen cannot separate representation effects from optimization variability. Completed summary dimensions shown here are 64, 32, 16, 8, 7, 6, 5, 4, 2. Intermediate integer dimensions investigate the originally observed 8-to-4 breakdown; one seed per size cannot establish a universal information cutoff. Only completed endpoints appear below; stopped partial fits are excluded. Mask-aware and moving-grid estimators are not trained by this comparison.
