# Manifest

What `tutorial/assets/` holds and where each file came from. The notebooks read these files and nothing else
in the repository. Tests check shipped files against the SHA-256 recorded below; optional native models
under `local-checkpoints/` are checked by their own bound loader. Paths are
relative to `tutorial/assets/`.

## How a file enters `tutorial/assets/`

Every file is written by a tool, never by hand:

| Folder | What | Written by |
|---|---|---|
| `results/calibration/` | Accepted study results (S1 to S9) | `lab/studies/accept.py`, which adds `ACCEPTED.json`: the source run, the SHA-256 of every source file and every change made. Two folders predate that record: `smile/` and `heston/prior-predictive/`, written by `lab/studies/smile_facts.py` (S2-1, S2-2); their next run goes through `accept.py` |
| `checkpoints/` | Historical BayesFlow 2.0 networks, retained unchanged as evidence | The original `lab/studies/accept.py` export stripped optimizer state and checked same-seed draws. The current participant environment never loads these files implicitly. New toy training is explicit and session-only. |
| `backbones/` | Hash-bound development cases from the current 100k estimators | `lab/studies/accept.py --replay` preserves bytes and scientific scope; `manifest.py` generates their catalogue. Native checkpoint exports preserve model bytes and metadata hashes. |
| `data/` | The exact Heston posterior on SPY (a feasibility run, not an accepted study) | `lab/checks/heston_spy_exact.py` |
| `quick-checks/`, `tasks/`, `images/` | Outputs of the lab's quick checks, the rough-Bergomi task file and two figures | `lab/studies/manifest.py`, as copies of the files named in the last column of the table |

Every result JSON records the task fingerprint, the bank manifest's SHA-256 and, where a network was used, the
checkpoint's SHA-256, so each file can be traced to its inputs. The banks themselves are not copied: each is
regenerated exactly from its configuration file and seed.

## The code behind the results

The studies ran on the lab's library, `lab/src/sbi4finance/calibration/`, with the simulators it imports
(`rough_bergomi.py`, `bergomi.py`, `hkde.py`). The notebooks do not import it: the functions they run live
(Black–Scholes and implied volatility, the Heston Fourier pricer, one rough-Bergomi smile, the network's adapter
and sampler) are copied unchanged into `tutorial/src/sbi4f_tutorial/`, and the lab's tests fail when a copy differs
from the lab's code or returns different numbers (`lab/tests/test_tutorial_parity.py`).
