## M8.2 — Reproducible inference and output

The pipeline card is deliberately short: the original
[checkpoint](../checkpoints/hkde-theta-intensity-provisional/model.keras), its
[task](../checkpoints/hkde-theta-intensity-provisional/task.json) and training
metadata specify the spline flow and train-only transforms. BayesFlow 2.0.14,
Keras 3.15.1 and JAX 0.11.1 are pinned in Pixi. The checkpoint remains labelled
**provisional as a standalone posterior**. It is the proposal component of the
new algorithm, not a newly trained accepted flow.

The inference layer adds a fixed 80% flow / 10% uniform / 10% product-arcsine
proposal, the original numerical likelihood, and self-normalized weights.
The prior remains uniform. The accepted
[two-contract surrogate](hkde-price-surrogate.md) produces matched downstream
prices. These are distributions of Q model prices, not realized payoffs,
physical-measure risks or tomorrow's market quotes. The nine likelihood prices
still use the numerical pricer; this route is not purely amortized inference.

[Correction evidence and commands](hkde-corrected-inference.md) connect the
configuration, checkpoint, source hashes, weight clouds and reports. Both the
2,048-proposal participant run and 8,192-proposal precision check must satisfy
the unchanged conditional/joint/price gates. Finite-pool SIR calibration uses
the participant budget. ESS is a reliability diagnostic, not a proof of mode
coverage; the independently refined references supply the accuracy comparisons.

## M8.3 — Participant lesson

Open [notebook10](../notebooks/10_hkde_corrected_workflow.py):

```bash

```

The suggested 30-minute segment covers the financial task and data roles,
importance correction, a provisional live joint posterior and price calculation,
diagnostics, and short exercises. The live path loads a saved **synthetic
validation panel** through the [local CSV/JSON interface](hkde-teaching-integration.md),
checkpoint and surrogate and uses 2,048 proposals. The panel and a cached
raw/corrected/reference price comparison are visible before live acceptance.
The corrected table uses the recorded 8,192-proposal precision sample, explicitly
separate from the live demonstration budget. Default execution reviews the cached
scientific evidence; the explicit demo command runs the fixed validation case.
Training, reference-grid pricing and base-bank generation
are never started by opening the lesson, and no cluster job is submitted.

Exercises distinguish priors from proposals, high ESS from validated accuracy,
SBC from conditional checks, joint draws from independent marginal sampling,
and model-price uncertainty from payoff risk. The numerical likelihood cost
and the raw neural failure are part of the lesson, not hidden setup work.

Offline execution verification requires a fresh process with external sockets blocked,
all market fixtures and raw training banks absent, and a headless HTML export
