# M8: an offline options teaching candidate

This delivery is one coherent synthetic **options candidate**, built from the
HKDE work in M4–M5 and the common M0–M2 conventions. It leaves the final
returns-versus-options curriculum choice open and preserves the MMAR example.
It does not require Heston's or rough Bergomi's unresolved inference studies to
pass, and it does not mark those branches accepted.

## M8.1 — Named task and evidence boundary

Use `hkde_boundary_defensive_importance_v2`, with the
[frozen protocol](hkde-correction-boundary-protocol.md) and existing
[HKDE task](../configs/tasks/hkde_inference_bank.json).

| Role | Exact meaning |
|---|---|
| Observation | Nine ordered European put prices `[batch,9,1]`, in currency, generated by the declared Fourier map plus independent Gaussian noise of SD 0.25. |
| Known context | Q measure; spot 100, rate 0.02, dividend 0; fixed contracts, initial variance 0.04 and remaining HKDE parameters. No market files are needed. |
| Unknowns | Joint long-run annual variance `theta` in `[0.025,0.065]` and annual jump intensity in `[0.25,1]`, with independent uniform priors. |
| Training labels | Synthetic parameters from the existing independent training bank. They never become conditioning inputs. |
| Participant output | Weighted joint parameter draws and distributions of the prices of excluded puts `(K=95,T=.75)` and `(K=80,T=1)`. |
| Validation truth | Synthetic labels, refined numerical posterior grids, and numerical expectation prices; none is a known real-market parameter or fair value. |
| Evidence | S only. Optional M would condition on a compatible real panel with frozen weights; optional E would need contemporaneous excluded target quotes and separately justified evaluation design. |

The original neural experiment, the first correction's reliability stop and the
independent surrogate audit stay visible. The fresh root-95026 test is reserved
for the fixed second correction, with no retraining or selection after outcomes.
The original neural root-62026 test is not opened.

## M8.2 — Reproducible inference and output

The pipeline card is deliberately short: the original
[checkpoint](../checkpoints/hkde-theta-intensity-provisional/model.keras), its
[task](../checkpoints/hkde-theta-intensity-provisional/task.json) and training
metadata specify the spline flow and train-only transforms. BayesFlow 2.0.14,
Keras 3.15.1 and JAX 0.11.1 are pinned in Pixi. The checkpoint remains labelled
**provisional as a standalone posterior**. It is the proposal component of the
new algorithm, not a newly trained accepted flow.

The inference layer adds a fixed 80% flow / 10% uniform / 10% product-arcsine
proposal, the original numerical likelihood, and self-normalized weights.
The prior remains uniform. The accepted
[two-contract surrogate](hkde-price-surrogate.md) produces matched downstream
prices. These are distributions of Q model prices, not realized payoffs,
physical-measure risks or tomorrow's market quotes. The nine likelihood prices
still use the numerical pricer; this route is not purely amortized inference.

[Correction evidence and commands](hkde-corrected-inference.md) connect the
configuration, checkpoint, source hashes, weight clouds and reports. Both the
2,048-proposal participant run and 8,192-proposal precision check must satisfy
the unchanged conditional/joint/price gates. Finite-pool SIR calibration uses
the participant budget. ESS is a reliability diagnostic, not a proof of mode
coverage; the independently refined references supply the accuracy comparisons.

## M8.3 — Participant lesson

Open [notebook10](../notebooks/10_hkde_corrected_workflow.py):

```bash
PYTHONPATH=src pixi run review-hkde-corrected
```

The suggested 30-minute segment covers the financial task and data roles,
importance correction, one live joint posterior and price calculation,
diagnostics, and short exercises. It loads a saved **synthetic validation
panel**, checkpoint and surrogate. Its default live calculation has 2,048
proposals. Training, reference-grid pricing, and base-bank generation are
cached; opening the lesson never submits a cluster job or starts a training run.

Exercises distinguish priors from proposals, high ESS from validated accuracy,
SBC from conditional checks, joint draws from independent marginal sampling,
and model-price uncertainty from payoff risk. The numerical likelihood cost
and the raw neural failure are part of the lesson, not hidden setup work.

Offline acceptance requires a fresh process with external sockets blocked,
all market fixtures and raw training banks absent, and a headless HTML export
with no cell errors. Measure loading, sampling/density, likelihood, target
pricing and reference comparison together. A notebook that merely skips its
live calculation because evidence is missing does not satisfy this acceptance.
